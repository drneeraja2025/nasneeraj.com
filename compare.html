How GuruVidyaZen School SISLMS lines up

This page is a friendly, high-level contrast between a reference SISMMS-style school data shape (rosters, period attendance, daily formative columns) and the GuruVidyaZen School SISLMS lane in this app. School SISLMS v1 is the K–8 class hub + daily log + assignments + non–performing-arts CCE + imports; other GuruVidyaZen academy types may expose arts modules and different CCE. It is not a legal spec — see in-app Legal and Help for the live feature set.

Scope: School SISLMS v1 is elementary and middle (K–8) in product positioning. Grades 9–12 are out of scope unless you add them later in planning.
Area Typical SISMMS / “school data” feel GuruVidyaZen School SISLMS (this train)
Tenant + isolation Per-school data boundaries expected. ✓ Row-level security by school_id — same isolation pattern as the rest of Gurukul; arts-only CCE and legacy flows are kept off the School shell via UI + product gates where needed.
Roster & class lists Students linked to classes / grades. ✓ Classes + enrollment + progress + roster pages with school-first copy; grades & sections catalog (K–8) and course_kind (batch vs subject offering) per parity map Option A.
Daily formative / attendance By date, often period or homeroom scoped. ✓ Daily log for School on daily_logs with preset-scaled score columns; actions aligned to the school daily log page in-app.
Assignments Tasks with due dates, submissions. ✓ Assignments + submissions with class and teacher scoping; school subtitle and class filter on the list; teacher preselect on create. Student submissions typically allow up to six attachment files (types and size caps in in-app Help).
Import / export Admin CSV expectations. ✓ Same import-export admin surface as the rest of the app; all operations scoped to the current school. Optional future CSV fields for 1117 grade/section columns documented in the runbook.
Calendar District calendars, feeds. ✓ iCal (.ics) import (works with Google Calendar exports) plus preset US / European / Indian holiday seeds (and optional regional presets such as Marathi where enabled). Not a live bidirectional Google sync—see in-app calendar Help.
PII in the UI Leaders need clarity on who sees contact fields. ✓ Student detail contact minimization for School roles (e.g. phone / address / guardian email visible to admin/owner; others see placeholders).
